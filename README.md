## 💫 About me

I'm a **Full Stack Developer** who graduated in Software Development from **ITLA** and is now pursuing a degree in **Computer Science at PUCMM**. I enjoy taking a product from idea to deploy: designing the interface, building the frontend and backend, and shipping it with a clean CI/CD pipeline.

I care about details: smooth animations, accessible interfaces, typed code, and READMEs that make a project easy to pick up.

- 🔭 **Currently building:** web experiences with Next.js, TypeScript and Tailwind CSS
- 🎓 **Studying:** Computer Science at PUCMM
- 🌱 **Learning:** Next.js App Router, motion design and modern DevOps tooling
- 👯 **Open to collaborate on:** fullstack, frontend and backend projects
- 💬 **Ask me about:** React, JavaScript, C#, .NET, SQL Server, Node.js and system design
- ⚡ **Fun fact:** I'm always listening to music while I code 🎧
